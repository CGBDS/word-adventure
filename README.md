# WORD ADVENTURE — La Máquina del Tiempo 🕰️🚀

Juego educativo móvil (HTML5) para aprender inglés desde A1 hasta A2 jugando.

**Jugar:** https://cgbds.github.io/word-adventure/

- 🟢 NOW · 🔵 BEFORE · 🟣 TOMORROW — viaja en el tiempo aprendiendo verbos
- 🏠 THE HOUSE OF TO BE — am/is/are, was/were, will be
- ⭐ Tiempos perfectos: have/has been, had been, will have been
- 6 minijuegos: elige, máquina del tiempo, construye, parejas, escucha, habla
- Voz en inglés (TTS), sonidos sintetizados, música alegre
- XP, monedas, rachas, tienda de accesorios, guardado automático
- 100% offline-friendly, sin cuentas, sin anuncios
